This struct is used to store the data points and their labels.

The struct has a label and three double values for the x, y, and z. The struct also has three constructors, a default constructor that initializes all varables to 0, a constructor that all varables can be inputed, and a constructor that has the label auto set to 0. \begin{DoxyAuthor}{Author}
